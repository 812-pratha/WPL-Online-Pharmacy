# WPL-Online-Pharmacy

MedEase - Online Pharmacy
 
A simple 4-page website built with basic HTML, CSS, and JavaScript.
 
Pages:
- index.html - Home
- login.html - Login
- register.html - Registration
- catalogue.html - Medicine catalogue
 
Files:
- style.css - shared styling
- script.js - form validation for login and register
- images/ - add your photos here (logo.png, home-banner.jpg, about-pharmacy.jpg, and product photos)
 
How to run:
Open index.html in any web browser.
